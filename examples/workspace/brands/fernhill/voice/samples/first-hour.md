Most of a dispatcher's day is decided before seven. If the board is right when the first van leaves, the rest is adjustments. If it's wrong, it's phone calls until noon.

We start with the runs that can't move: fixed-time pickups and anything a client has already confirmed. Everything else fits around them. It sounds obvious, but it's the step people skip when the phones start early.
